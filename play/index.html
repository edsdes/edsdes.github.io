红莉栖 · 调试时间
让旧程序走进 win()

    

    

      
      

        

          
先别急，我陪你看。把地址放对以后，还要检查一下对齐。

          
        

        
选填充长度和返回地址。下面的内存会跟着变；地址放对以后，看看进入 win() 时还缺什么。

        
64 位教学模型：buf 16 字节 → 保存的 RBP 8 字节 → 返回地址 RIP 8 字节。win() 入口要求 RSP % 16 = 8。

      

    

    
baby-stack.c
char buf[16];
read_unchecked(buf);   // 模型里的输入函数，没有长度检查
// win() 里的 aligned_call 要求入口 RSP % 16 == 8
// ret() = 0x401016：多弹一个 8 字节地址

    

      
      

        
        
        
        字节
      

      
然后接上这个 8 字节地址
        
        
        
      

      
      
这个 ret() 会再弹出一个 8 字节地址，接着走向你选的目标。

    

    

      
缓冲区 buf · 16 字节

      
保存的 RBP · 8 字节

      
返回地址 RIP · 8 字节

      
下一个地址 · 8 字节

    

    
当前返回地址 0x401080

    read → ret → main()
    先调整返回地址，再检查 win() 的入口对齐。
    
技术提示
先数格子：16 字节 buf 后面，还有 8 字节保存的 RBP。返回地址从偏移 24 开始。
再选目标：让程序进入 win()。地址以小端序写入；淡紫色是填充，绿色是地址。
最后看对齐：直接返回 win() 时，入口 RSP % 16 = 0。让 ret() 先多弹一个 8 字节地址，再走到 win()，余数才会变成 8。这是本页的 64 位教学模型。
